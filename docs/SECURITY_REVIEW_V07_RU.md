# Telegram Vault Exporter — безопасность и критерии первого тестового APK (v0.7)

## Принципы

1. Только авторизованный пользователь экспортирует доступные ему облачные чаты.
2. Прямое соединение с Telegram через официальную TDLib, никаких собственных серверов.
3. Основная сессия Telegram и сеанс экспортёра изолированы.
4. Расшифрованные медиа могут временно находиться в TDLib-кэше. Минимизировать их хранение, но абсолютную гарантию уничтожения на флеш-накопителе дать нельзя.
5. Защита архива отдельным паролем; промежуточные данные зашифрованы ключом, защищённым Android Keystore.
6. Архив никогда не объявляется завершённым из-за серии неудачных или повторных запросов. Ошибки показываются пользователю.
7. После подтверждённого завершения сеанса требуется удалить данные отдельного клиента. Не отключать основной Telegram.
8. GitHub Actions используется ТОЛЬКО для компиляции исходников, а не для пользовательских данных или авторизации.

## Обязательное до публичного APK

- Собрать настоящую официальную libtdjson.so для arm64-v8a и проверить ABI/версии.
- Проверить собственные Telegram API ID/hash разработчика; не использовать тестовые API ID в публичном выпуске.
- Проверить вход, обработку ошибок, анти-flood ожидания и явное подтверждение завершения Telegram-сеанса.
- Реализовать Foreground Service для долгого экспорта и уведомление об остановке.
- Добавить полный список медиа, исключения, manifest и отчёт о недоступных файлах; сравнить выгрузку с Telegram Desktop на контрольном чате.
- Поддержать свободное место, большое количество файлов, отмену и устойчивый resume после process-kill.
- Изолировать данные в app-private хранилище, запретить резервное копирование, протестировать удаление кэша.
- Провести статический аудит, инструментальные Android-тесты, анализ сетевого трафика, аудит зависимостей и воспроизводимость APK.
- Настроить подписывание релизных APK; не распространять сборку, собранную из недоверенных бинарных зависимостей.

## Не гарантируем

- Восстановление удалённых для всех сообщений, секретных чатов и файлов, к которым нет доступа.
- Нулевой риск блокировок Telegram или утечек на взломанном/заражённом устройстве.
- Побайтовую идентичность с Telegram Desktop HTML/JSON; нужен отдельный парсер для формата `.tva`.

## Состояние

Java-криптотесты запускались локально; нативный Android APK не собирался и не тестировался.
