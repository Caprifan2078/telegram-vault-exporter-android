# Vault Exporter — запреты на публичный выпуск и план проверки

## Ключевое правило
Нельзя гарантировать нулевую вероятность блокировки аккаунта Telegram или нулевую вероятность утечки. На странице `core.telegram.org/api/obtaining_api_id` Telegram заявляет о дополнительном наблюдении за пользователями неофициальных API-клиентов. Применение Takeout API не превращает сторонний клиент в официальный.

## Минимизация риска блокировок
1. Приложение называется Vault Exporter и обозначено как независимый клиент Telegram API.
2. Собственный API ID разработчика; никакого тестового API ID в публичном релизе.
3. Запросы ограничиваются чтением истории выбранных пользователем чатов и скачиванием вложений.
4. FLOOD_WAIT обязателен: ждать предписанный интервал или сохранять прогресс и завершать работу. Не переключать номера, IP-адреса или ключи для обхода ограничений.
5. Экспортировать только доступные пользователю и разрешённые к сохранению сообщения.
6. До релиза отдельно проверить Takeout API на тестовом аккаунте, не выдавая обычный TDLib getChatHistory за официальную Takeout-выгрузку.
7. Независимая оценка соответствия всем API Terms и Security Guidelines Telegram.

## Минимизация риска утечки
1. Только сеть TDLib→Telegram. Никаких собственных backend API, crash-report SDK, рекламы, аналитики, WebView.
2. Запрет Android backup и передачи app-private данных; приложение не запрашивает доступ ко всем файлам, контактам, SMS.
3. Кэш TDLib может содержать незашифрованные временные медиа. Требуется проверить реальную очистку на Android и поведение при падении/отключении питания.
4. Пароль контейнера хранить только в памяти до окончания задачи; пароль входа не сохранять.
5. Никогда не отправлять личный экспорт в GitHub Actions. Только исходники и тестовые вымышленные чаты.
6. Полная проверка .tva до успеха; при недоступном файле показать отдельную ошибку и не объявлять выгрузку полной.
7. При сохранении проверять, что конечное место локальное; предупреждать про авто-бэкап папок пользователя.

## Блокирующие пункты для готового APK
- [ ] Реально собрать и установить APK с официальной TDLib pinned commit.
- [ ] Проверить авторизацию/код/2FA/выход только на тестовом аккаунте.
- [ ] Выгрузить тестовый чат со снятым кэшем и сравнить число и качество файлов с Telegram Desktop.
- [ ] Проверить сетевой трафик: только Telegram DC, без иных запросов приложения.
- [ ] Ввести foreground service с безопасными паузой и отменой при Android background/doze.
- [ ] Выдержать остановку процесса, дефицит места, переподключения и много гигабайт.
- [ ] Подтвердить отсутствие открытых копий в Android MediaStore / резервной копии.
- [ ] Пройти аудит зависимостей, APK-подписи, полномочий, управления сессией и криптографии.
- [ ] Реализовать Takeout с учётом split ranges либо официально обозначить ограничения обычной TDLib выгрузки.
- [ ] Получить согласие пользователя на вход в отдельный сторонний клиент с реальным объяснением рисков.

До завершения этих пунктов исходники — прототип, а не программа для хранения личных архивов.
