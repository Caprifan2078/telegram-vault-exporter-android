# Автоматическая сборка APK без команд у пользователя

Это документация **разработчика приложения**. Конечному пользователю нужен только APK. Ему не нужно регистрировать Telegram API-приложение или вводить команды.

## Почему здесь нет готового APK

В офлайн-среде отсутствуют Android SDK/NDK/Gradle и официальная Android `libtdjson.so`. Подменять их непроверенными бинарниками или выпускать пустой APK **запрещено**. API ID и hash принадлежат *разработчику* приложения; их нужно зарегистрировать один раз в `my.telegram.org`.

## Путь через GitHub Actions (все команды выполняются на сборочном сервере автоматически)

1. Разработчик помещает исходный проект в **закрытый репозиторий GitHub**, включая `.github/workflows/build-debug-apk.yml`. Не добавлять личные Telegram-коды, телефон, резервные копии переписок или файлы TDLib сессии в репозиторий.
2. В Settings → Secrets and variables → Actions создаёт два секрета: `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Значения берутся из собственного приложения разработчика на my.telegram.org, **не от пользователя**.
3. В Actions запускает workflow `Build Telegram Vault APK` кнопкой **Run workflow**.
4. CI скачивает **исходники официальной TDLib**, собирает Android-движок JSON, запускает тесты шифрования, восстановления после прерывания и пробной архивной цепочки, компилирует приложение и отклоняет сборку без TDLib.
5. Результат `app-debug.apk` вместе с SHA-256 доступен в Artifacts после успешного завершения. Этот APK для **тестирования**, а не публичного выпуска.

CI использует сервера GitHub только для **сборки исходного кода**. Ни переписки, ни коды входа, ни созданные пользователем архивы туда не загружаются. Готовое приложение для получения данных подключается непосредственно к Telegram.

## До первого реального экспорта

Обязательно установить APK на Android и проверить: вход, выбор чата, выгрузку обычных сообщений, голосовых/кружочков, наличие медиа, неполные файлы, проверку архива, выход только из сеанса экспортёра, сеть без непредусмотренных соединений. Сделать внешний аудит безопасности.
