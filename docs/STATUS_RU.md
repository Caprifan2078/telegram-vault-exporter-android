# Состояние разработки Telegram Vault Exporter

- Android alpha-прототип, а не подтверждённая безопасная release APK.
- Исходники включают код экспорта, локальные синтетические фикстуры, шифрование, проверку архива и тесты.
- Полный интеграционный тест `TestHardenedExportEngine` ранее останавливался на `expected history outage`. Это известный блокер; успешный прогон полного набора не заявляется.
- Официальная Android `libtdjson.so` пока отсутствует. Для функционального Telegram-клиента нужен воспроизводимый билд официальной TDLib.
- Вход в настоящий Telegram, поведение на Android и сетевой трафик независимо не тестировались. Не использовать основной аккаунт до подтверждения.
- Workflow `.github/workflows/public-offline-qa.yml` тестирует только офлайн-Java и статические проверки на стандартных GitHub-hosted runners. Он пропускает задания, пока репозиторий Private, чтобы не тратить платные минуты.
- После переключения в Public workflow можно запустить вручную или при push в main. **Он не собирает APK и не выполняет вход в Telegram.** Результаты прогонов до фактического выполнения неизвестны.
- В CI не передавать настоящие переписки, сессии, телефонные номера, Telegram API ID/hash или пароль.
- Релиз заблокирован до прохождения `docs/RELEASE_GATES_RU.md`. Не выдавать исходники alpha за готовую APK.

Никогда не добавлять личные данные, реальные Telegram-сессии, записи экрана, API credentials и токены в репозиторий, артефакты GitHub Actions или публичные issues.
