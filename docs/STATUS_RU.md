# Состояние разработки Telegram Vault Exporter

- Android alpha-прототип, а не подтверждённая безопасная release APK.
- Источники: код экспорта, локальные фикстуры, шифрование, проверка архива и тесты.
- Интеграционный тест `TestHardenedExportEngine` ранее останавливался на утверждении `expected history outage`. Этот сценарий нужно исправить, заново выполнить полный набор и записать реальные результаты.
- Официальная Android `libtdjson.so` в репозитории отсутствует. Для полноценного Telegram-клиента требуется воспроизводимая установка официальной TDLib.
- Реальный вход в Telegram, безопасность и сетевой трафик на Android не проходили независимый аудит. Не подключать основной аккаунт до проверки.
- GitHub Actions workflow отсутствуют; перед включением CI убедиться, что используются только безопасные тестовые данные и минимальные разрешения.
- Релиз блокируется, пока не пройдены проверки из `docs/RELEASE_GATES_RU.md`.

Никогда не добавлять реальные Telegram-сессии, личные переписки, API ID/hash, номера телефонов, скриншоты, записи, секреты или незашифрованные тестовые архивы в коммиты, CI и релизы.
