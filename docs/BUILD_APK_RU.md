# Как сделать настоящий APK (инструкция ДЛЯ РАЗРАБОТЧИКА, не пользователя)

Рядовому пользователю нужен только уже собранный и подписанный `*.apk`.
**Никогда** не просите пользователя устанавливать Termux или вводить Gradle-команды.

Этот репозиторий — исходная Android-программа, НЕ готовый APK.
Для повторяемой безопасной сборки нужны официальные Android Studio + SDK 35,
NDK + CMake 3.22.1, JDK 17, Gradle 8.7+, TDLib для Android.

1. Взять **официальные** исходники TDLib: https://github.com/tdlib/td
   и собрать libtdjson.so в режиме JSON для ABI `arm64-v8a`, по инструкции
   https://github.com/tdlib/td/tree/master/example/android . Не устанавливать
   непроверенные libtdjson.so из чатов, файлообменников или случайных APK.
2. Поместить полученный `libtdjson.so` в `app/src/main/jniLibs/arm64-v8a/`.
   Мост `libvaultbridge.so` соберёт Android Gradle Plugin через CMake.
3. Зарегистрировать **собственное приложение разработчика** на https://my.telegram.org,
   получить app api_id и api_hash. Это не пользовательские данные. Разработчик
   задаёт значения через Gradle properties `telegramApiId=...`,
   `telegramApiHash=...` в локальном `~/.gradle/gradle.properties`
   или через защищённую систему CI. Не складывать данные в репозиторий.
4. Открыть проект в Android Studio, запустить Gradle sync, собрать `assembleDebug`
   для тестирования. Без официальной TDLib `.so` Gradle принудительно остановит сборку:
   загружаемый APK без рабочего Telegram-движка выпускать нельзя.
5. Проверить `adb shell dumpsys package org.vault.exporter` на единственный
   INTERNET permission, трафик только к ожидаемым Telegram endpoint'ам,
   SHA-256 APK, подпись, реальную авторизацию, выбор чата, медиа, выход,
   приостановку и повреждённый архив. Release APK подписывать отдельным ключом
   и распространять с проверяемым SHA-256/подписью.

## Важно: ограничения
Этот проект рассчитан на arm64 Android 8+, необходима окончательная проверка
доступности ABI/NDK, согласованности версии TDLib API и совместимости ОС.
Реальный APK в текущей среде **не был собран**, TDLib бинарники в ZIP **не входят**.
