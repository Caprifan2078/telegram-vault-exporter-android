# Telegram Vault Exporter

Экспериментальный Android-проект для экспорта доступных пользователю Telegram-данных в зашифрованный архив, с проверкой целостности и возможностью возобновления работы.

## Текущий статус

**Alpha, не готовый релиз для настоящего Telegram-аккаунта.** Исходники содержат движок экспорта, Android-интерфейс, мост TDLib, сценарные и офлайн-тесты. Полная независимая Android-сборка, реальное соединение и стабильность эксплуатации не подтверждены.

- Для полноценной APK требуется собрать и проверить официальную `libtdjson.so` для Android arm64. Готовая нативная библиотека в репозитории отсутствует.
- Один интеграционный сценарий `expected history outage` требует исправления и повторной проверки.
- Тестовые переписки и тестовый медиаконтент — вымышленные, не реальные данные Telegram.

## Приватность и безопасность

- Не коммитить реальные Telegram-архивы, сессии, телефонные номера, скриншоты, личные медиа, логи, ключи и Telegram API ID/hash.
- Не передавать настоящие пользовательские данные в GitHub Actions и не включать секреты в APK или build artifacts.
- Для разработки использовать изолированные тестовые сценарии и отдельные QA-ветки; `main` изменять после проверки.
- Не импортировать стороннюю Git-историю с неизвестным авторством и приватными метаданными.
- Использовать только официальные проверенные зависимости, минимальные разрешения CI и стандартные runners.
